## Why

Режим `summary` хранит резюме отдельно от сообщений и подставляет его в prompt вместо старой истории, но увидеть само резюме из интерфейса нельзя: `/facts` показывает память фактов, а для summary такой команды нет. Задание дня 9 требует показать, что резюме действительно хранится отдельно и именно оно уходит в запрос, — без команды просмотра это остаётся невидимым и на экране, и при отладке стратегии.

## What Changes

- Добавляется slash-команда `/summary`: печатает сохранённое резюме активной ветки и watermark (id сообщения, по которое резюме построено).
- При отсутствии резюме команда сообщает `summary:\n(no summary)` по образцу `/facts`.
- `/help` и README week-02 перечисляют команду.
