# Day 4

## Задание

Выполните один и тот же запрос с параметрами:
- `temperature = 0`
- `temperature = 0.7`
- `temperature = 1.2`

Сравните ответы по точности, креативности и разнообразию. Сформулируйте,
для каких задач лучше подходит каждая настройка.

Результат: примеры ответов с разной температурой и выводы по их
использованию.

## Что делает

Один и тот же запрос (system + user зашиты в коде) отправляется с тремя
температурами, по 3 прогона на каждую — итого 9 запросов к Groq.
Три прогона нужны потому, что разнообразие видно только между повторами:
по одному ответу на температуру про разброс сказать нечего.

Запрос устроен из двух половин, чтобы одним промптом мерить и точность, и
креативность:
- фактическая половина — объяснить TCP handshake. Правильный ответ ровно
  один: SYN → SYN-ACK → ACK, отклонение сразу видно.
- открытая половина — придумать метафору. Правильного ответа нет, есть
  только более и менее удачные.

Плюс system-промпт задаёт жёсткий формат вывода (два пункта, метафора
одним предложением) — соблюдение формата тоже деградирует с ростом
температуры.

После каждой температуры печатаются два числа:
- средняя попарная схожесть ответов (Jaccard по множествам слов): 1.00 —
  ответы дословно из одних и тех же слов, ниже — расходятся;
- сколько пар прогонов совпали дословно.

Это грубая метрика, но она переводит «разнообразие» из ощущения в число.

Итоги сравнения — в [REPORT.md](REPORT.md).

## Про лимиты Groq

`max_tokens=600` и `reasoning_effort=low` подобраны под free tier:

- gpt-oss тратит часть бюджета ответа на reasoning-токены. При
  `max_tokens=300` видимый ответ обрывался на полуслове, а один прогон на
  `temperature=1.2` вернул пустую строку — метрика разнообразия при этом
  меряла обрезание, а не сэмплирование.
- Groq списывает с лимита 8000 токенов/минуту *запрошенные* `max_tokens`, а
  не фактически использованные. При `max_tokens=800` девятый запрос падал с
  429 (`Limit 8000, Used 7206, Requested 964`). 600 × 9 в лимит укладывается.

Два полных прогона подряд в одну минуту всё равно упрутся в 429 — это
ожидаемо, подождите минуту.
