# Day 4

## Задание

Выполните один и тот же запрос с параметрами:
- `temperature = 0`
- `temperature = 0.7`
- `temperature = 1.2`

Сравните ответы по точности, креативности и разнообразию. Сформулируйте,
для каких задач лучше подходит каждая настройка.

Результат: примеры ответов с разной температурой и выводы по их
использованию.

## Что делает

Вопрос задаётся через CLI (аргументом или в интерактивном приглашении),
отправляется в Groq три раза — с `temperature=0`, `0.7`, `1.2` — и три
ответа выводятся рядом, в одной таблице по три колонки.

## Usage

```
export GROQ_API_KEY=...
go run . "Объясни, что такое TCP handshake, и придумай для него метафору"
```

Без аргументов вопрос запрашивается интерактивно (`Вопрос: `).

## Про лимиты Groq

`max_tokens=600` и `reasoning_effort=low`: gpt-oss тратит часть бюджета
ответа на reasoning-токены, слишком тесный лимит обрезает видимый ответ
на полуслове.
