# Day 3

## Задание

Возьмите одну задачу (логическую, алгоритмическую или аналитическую).

Решите её через API четырьмя способами:
- получите прямой ответ без дополнительных инструкций
- добавьте в промпт инструкцию: «решай пошагово»
- попросите модель сначала составить промпт для решения задачи, а затем
  используйте его
- создайте в промпте группу экспертов (например: аналитик, инженер, критик)
  и получите решение от каждого

Сравните:
- отличаются ли ответы
- какой способ дал наиболее точный результат

Результат: несколько решений одной задачи и их сравнение.

## Что делает

Задача зашита в коде: [LeetCode 3904, Smallest Stable Index II](https://leetcode.com/problems/smallest-stable-index-ii/).
Каждый способ обязан вернуть код решения на Python
(`def stable_index(nums: list[int], k: int) -> int`), а не просто число —
корректность каждого решения проверена отдельно скриптом на примерах из
условия + 500 случайных тестов против brute-force (см. REPORT.md).

`task` (user-сообщение) — чистое условие задачи, без прочих указаний. Все
доп. инструкции идут через `system`-роль: требование кода/O(n)/краткости
(`baseSystemPrompt`), "решай пошагово" (добавка к `baseSystemPrompt`),
инструкция для генерации мета-промпта, персона эксперта (`baseSystemPrompt`
+ роль).

Делает 7 запросов к Groq и печатает результат каждого способа:
1. прямой ответ (`system` = `baseSystemPrompt`)
2. пошаговое рассуждение (`system` = `baseSystemPrompt` + инструкция "решай пошагово")
3. мета-промпт: сначала модель составляет промпт для решения задачи
   (`system` = отдельная инструкция), затем этот промпт используется как
   отдельный запрос без нашего `baseSystemPrompt`
4. панель экспертов: 3 независимых запроса, `system` = `baseSystemPrompt`
   + персона (аналитик, инженер, критик)

Сравнение способов — не автоматизировано в коде, делается вручную по
выведенным ответам (итог — в REPORT.md).

Ответ ограничен `max_tokens=1024` и промптом просить быть кратким: без
этого модель уходила в формальные доказательства теорем на 5-6k токенов
за один вызов и упиралась в лимит Groq free tier (8000 токенов/минуту).

## Usage

```
export GROQ_API_KEY=...
go run .
```

Без аргументов — задача и все промпты зашиты в коде.
