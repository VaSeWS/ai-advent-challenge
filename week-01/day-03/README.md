# Day 3

## Задание

Возьмите одну задачу (логическую, алгоритмическую или аналитическую).

Решите её через API четырьмя способами:
- получите прямой ответ без дополнительных инструкций
- добавьте в промпт инструкцию: «решай пошагово»
- попросите модель сначала составить промпт для решения задачи, а затем
  используйте его
- создайте в промпте группу экспертов (например: аналитик, инженер, критик)
  и получите решение от каждого

Сравните:
- отличаются ли ответы
- какой способ дал наиболее точный результат

Результат: несколько решений одной задачи и их сравнение.

## Что делает

Задача передаётся аргументом командной строки, не зашита в коде — один и
тот же бинарник решает любую задачу (логическую, алгоритмическую,
аналитическую) любым из четырёх способов. Способ выбирается флагом
`-method`, за один запуск выполняется только он (не все четыре подряд):

- `direct` — прямой ответ, system-сообщения нет вообще
- `step` — system = `"Решай пошагово: распиши ход рассуждений перед
  финальным ответом."`
- `meta` — сначала отдельным запросом генерируется самодостаточный промпт
  для задачи, затем он используется как единственное сообщение во втором
  запросе (без исходного `task` и без system-инструкций)
- `panel` — три независимых запроса с одной и той же задачей, system =
  только персона (аналитик/инженер/критик), без общих для методов
  требований

Ни один system-промпт не содержит формулировки конкретной задачи и не
требует конкретного формата ответа — эти инструкции полностью описывают
только сам способ рассуждения и подходят к любой задаче, переданной через
аргументы. Формат ответа (если он важен) — часть текста задачи, которую
передаёт пользователь, а не зашитой в код system-роли.

Модель `openai/gpt-oss-20b` на Groq — reasoning-модель: она тратит
`max_tokens` в основном на скрытое поле `reasoning`, прежде чем написать
видимый ответ. При настройках API по умолчанию один вызов сжигал ~950 из
1024 токенов на скрытое рассуждение и возвращал пустой `content`. Решение —
`reasoning_effort: "low"` в каждом запросе (тот же приём, что и в дне 2)
плюс увеличенный `max_tokens=2048`. Даже так расход токенов на скрытое
рассуждение случаен — многословные способы (`step`, критик из `panel`)
иногда всё ещё упираются в лимит с пустым ответом; тогда достаточно
перезапустить.

Сравнение способов — не автоматизировано в коде, делается вручную по
выведенным ответам (пример прогона и разбор — в REPORT.md).

## Usage

```
export GROQ_API_KEY=...
go run . -method=direct|step|meta|panel <задача>
```

Пример:

```
go run . -method=panel "Решите головоломку: ..."
```
