# Day 5

## Задание

Выполните один и тот же запрос на слабой, средней и сильной модели (например,
из начала, середины и конца списка HuggingFace). Замерьте время ответа,
количество токенов, стоимость (если модель платная). Сравните качество
ответов, скорость, ресурсоёмкость.

Результат: короткий вывод о различиях между моделями + ссылки.

## Что делает

Один и тот же промпт (классическая задача на когнитивную рефлексию —
"бита и мяч", Frederick, 2005 — интуитивный ответ 10 неверен, правильный
ответ 5 требует секунды реального рассуждения) отправляется без изменений
трём моделям Groq подряд:

| Модель | Условный уровень | Цена (вход / выход за 1M токенов) |
|---|---|---|
| `openai/gpt-oss-20b` | слабая (20B) | $0.075 / $0.30 |
| `qwen/qwen3.6-27b` | средняя (27B) | $0.60 / $3.00 |
| `openai/gpt-oss-120b` | сильная (120B) | $0.15 / $0.60 |

Модели выбраны по [console.groq.com/docs/models](https://console.groq.com/docs/models)
(проверено 2026-09-05) как единственные три чат-модели Groq, у которых
одновременно есть публичная цена за токен и на входе — заметный разброс
размера. `llama-3.1-8b-instant` и `llama-3.3-70b-versatile` исключены: с
2026-08-26 Groq перевёл обе на Enterprise-only "Contact Sales" — публичной
цены за токен для них больше нет.

Для каждой модели печатается: время ответа (`time.Since`), токены
(`prompt` / `completion` / `total` из поля `usage` ответа Groq), стоимость
(посчитана по токенам и захардкоженным ценам из таблицы выше) и сам ответ.

Сравнение качества/скорости/ресурсоёмкости — не автоматизировано, делается
вручную по выведенным данным (итог — в REPORT.md).

## Usage

```
export GROQ_API_KEY=...
go run .
```

Без аргументов — промпт и список моделей зашиты в коде.
