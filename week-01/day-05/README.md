# Day 5

## Задание

Выполните один и тот же запрос на слабой, средней и сильной модели (например,
из начала, середины и конца списка HuggingFace). Замерьте время ответа,
количество токенов, стоимость (если модель платная). Сравните качество
ответов, скорость, ресурсоёмкость.

Результат: короткий вывод о различиях между моделями + ссылки.

## Что делает

Промпт задаётся через аргументы CLI (по умолчанию — классическая логическая
загадка про братьев и сестру, см. Usage) и без изменений уходит трём
моделям Groq подряд. Модели выбраны не по номинальному размеру, а по
независимому бенчмарк-рангу (MMLU / MMLU-Pro, проверено 2026-09-06) —
топ, средняя и аутсайдер:

| Модель | Ранг | MMLU / MMLU-Pro | HuggingFace |
|---|---|---|---|
| `openai/gpt-oss-120b` | топ | MMLU 90.0 | [openai/gpt-oss-120b](https://huggingface.co/openai/gpt-oss-120b) |
| `qwen/qwen3.6-27b` | средняя | MMLU-Pro 86.2 | [Qwen/Qwen3.6-27B](https://huggingface.co/Qwen/Qwen3.6-27B) |
| `openai/gpt-oss-20b` | аутсайдер | MMLU 85.3 | [openai/gpt-oss-20b](https://huggingface.co/openai/gpt-oss-20b) |

Это те же три модели, что и раньше (единственные на Groq с одновременно
публичной ценой за токен и стабильным доступом на этом ключе) —
`llama-3.1-8b-instant` и `llama-3.3-70b-versatile` по-прежнему
Enterprise-only с 2026-08-26 (подтверждено повторно: 404
`model_not_found` при попытке их вызвать).

Ответы всех трёх моделей выводятся бок о бок одной таблицей (3 колонки,
`text/tabwriter`, с ручным переносом текста по словам — иначе один
сплошной абзац разносит ширину колонки).

Сравнение качества/скорости/многословности — не автоматизировано, делается
вручную по выведенной таблице (итог — в REPORT.md).

## Usage

```
export GROQ_API_KEY=...
go run .                      # промпт по умолчанию — загадка про братьев и сестру
go run . "свой промпт"        # тот же промпт уходит всем трём моделям
```
