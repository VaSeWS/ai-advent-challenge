# Видео-демо дня 1

Скринкаст без звука: терминал сам печатает команды и гоняет реальный код из
`week-01/day-01/main.go` — задание, структура запроса, обработка ошибок,
два живых ответа Groq. Длительность ~70 секунд.

- `demo.sh` — самоиграющее демо (эффект набора, реальные запуски)
- `record.sh` — открывает окно Terminal, играет демо, пишет экран в `.mp4`
- `upload_yadisk.sh` — заливает файл на Яндекс.Диск, печатает публичную ссылку

Ключ на экран не попадает: `demo.sh` печатает замаскированную строку
`export GROQ_API_KEY=gsk_••••`, а настоящий ключ `record.sh` читает из `.env`
внутри временного лаунчера.

## Запись

Один раз выдать разрешение:

1. System Settings → Privacy & Security → Screen & System Audio Recording
2. Включить приложение терминала, из которого запускаешь
3. Перезапустить это приложение

Потом:

```
./week-01/day-01/video/record.sh
```

Скрипт сам проверит разрешение, откроет окно 1280×800, дождётся конца демо,
остановит запись и напечатает путь к `day-01-demo.mp4`. Пока идёт запись,
окно Terminal трогать не нужно.

Настройки: `SPEED` (задержка на символ, по умолчанию `0.025`), `PAUSE`
(пауза между шагами), `X`/`Y`/`W`/`H` (геометрия окна и области записи).
Для читаемости в видео имеет смысл поднять размер шрифта в профиле Terminal
до 16–18 pt перед записью.

Прогнать демо без записи:

```
export GROQ_API_KEY=...
./week-01/day-01/video/demo.sh
```

## Загрузка на Яндекс.Диск

Приложения Яндекс.Диска и `yandex-disk` CLI в системе нет, поэтому заливка
идёт через REST API. Токен берётся на https://yandex.ru/dev/disk/poligon/:

```
export YANDEX_DISK_TOKEN=...
./week-01/day-01/video/upload_yadisk.sh week-01/day-01/video/day-01-demo.mp4
```

Скрипт печатает публичную ссылку. `NO_PUBLISH=1` — залить без публикации.
Альтернатива без токена: перетащить `.mp4` в веб-интерфейс disk.yandex.ru.

Сам `.mp4` в git не коммитится (см. `.gitignore` рядом).
