# День 16 — локальный погодный MCP

## Задание

Подключить MCP-клиент к серверу, запросить `tools/list` и вывести доступные инструменты.

## Запуск

```sh
go run ./week-04/day-16
go run ./week-04/day-16 -weather
```

Первая команда запускает локальный MCP-сервер как дочерний процесс по stdio, выполняет MCP-соединение и печатает ответ сервера на `tools/list` с описанием входных параметров. Вторая дополнительно вызывает `current_weather` для координат Москвы и показывает ответ [Open-Meteo](https://open-meteo.com/en/docs) в реальном времени. Ключ API не нужен; для второго вызова необходим интернет.

Режим `server` запускает тот же сервер отдельно, например для другого MCP-клиента: `go run ./week-04/day-16 server`. Обычный вывод сервера занят протоколом MCP.
