# День 17 — собственный MCP Яндекс Диска

## Задание

Зарегистрировать собственный MCP-инструмент с описанными входными параметрами, вызвать его из агента и использовать результат.

## Запуск

```sh
export YANDEX_DISK_TOKEN=... # OAuth-токен Диска с правом записи
export GROQ_API_KEY=...       # нужен только для команды agent

go run ./week-04/day-17 list
go run ./week-04/day-17 agent week-04/day-17/video/source-day-16.mp4
```

`list` устанавливает локальное MCP-соединение по stdio и выводит `publish_video` и его JSON Schema. `agent` передаёт схему инструментов Groq, получает вызов `publish_video`, направляет его на MCP-сервер и передаёт публичную ссылку обратно модели. Запись должна существовать до запуска. Без LLM тот же инструмент вызывается через `go run ./week-04/day-17 upload <путь-к-файлу>`.

Для `video/demo.sh` сначала скопируйте уже записанное видео дня 16 в
`week-04/day-17/video/source-day-16.mp4` (до удаления локальной копии после
публикации) либо скачайте опубликованное видео с Диска по его публичной
ссылке. Во время записи дня 17 исходный файл должен оставаться доступным:
записываемое видео ещё не существует и не может загрузить само себя.

Инструмент принимает только локальный `week-NN/day-NN/video/*.mp4` в текущем репозитории, создаёт папки на Диске, запрашивает URL загрузки, передаёт файл, публикует его и возвращает `{ "path": "...", "public_url": "..." }`. Имя файла сохраняется: `day-17-demo.mp4` попадает в `/ai-advent-challenge/week-4/day-17-demo.mp4`. Повторная загрузка файла с тем же именем заменяет прежний объект. Никакие токены не записываются в исходники или вывод. Go-код читает их только из переменных окружения, а не из `.env`.

Для записи других дней Claude-скилл по-прежнему вызывает `.claude/skills/record-task-demo/scripts/upload_yadisk.sh <файл>`: скрипт загружает через **этот MCP-клиент** и удаляет локальную копию только после получения публичной ссылки. Скрипт умеет взять токен из локального `.env`; сервер Go этого не делает. При ошибке публикации файл остаётся локально. Видео снимается только после утверждения плана кадров.

Если VPN выдаёт недоступный IPv6-адрес Диска (ошибка `socket is not connected`), запускайте загрузку с `YANDEX_DISK_IPV4=1`: MCP-клиент использует IPv4 только для этого процесса. По умолчанию системный выбор адреса не меняется. На медленном соединении клиент допускает до 10 минут на HTTP-запрос и до 12 минут на всю команду.

API: [Яндекс Диск](https://yandex.com/dev/disk-api/doc/en/); [MCP Go SDK](https://go.sdk.modelcontextprotocol.io/quick_start/).
