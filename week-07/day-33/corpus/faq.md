# Частые вопросы по iRon (синтетическая база поддержки)

Материал предназначен для поиска ответов по русским формулировкам и английским названиям параметров. Сценарии и CRM-профили в демонстрации синтетические; это не отчёт о проверке приложения на Windows. Ответы ниже ограничены опубликованным README iRon: режимы и поведение, не описанные там, неизвестны.

## Overlays / оверлеи не видны в машине

**Вопросы для поиска:** «не вижу оверлеи в машине», «overlay не появляется», «не видно в car», «iRacing borderless», «окно без рамки».

README говорит, что после запуска iRacing, когда вы уже находитесь в машине, overlays должны появиться. В README рекомендован оконный режим **borderless** (без рамки). Там же прямо сказано: overlays могут работать и в других режимах, но автор их не проверял. Поэтому borderless — документированная рекомендация, а работа в других режимах не подтверждена. Источник: upstream `README.md`, строки 114–116 (раздел *Installing & Running*).

## Как передвинуть или изменить размер overlays — Alt+J

**Вопросы для поиска:** «переместить оверлей», «передвинуть overlay», «изменить размер», «resize», «Alt+J», «ALT-j».

Нажмите **Alt+J** (в README написано `ALT-j`), чтобы войти в режим перемещения и изменения размера. В этом режиме оверлеи можно передвигать мышью; размер меняется перетаскиванием нижнего правого угла. Нажмите Alt+J ещё раз, чтобы вернуться в обычный режим. Источник: upstream `README.md`, строка 122 (раздел *Configuration*).

## Где config.json и почему файла ещё нет

**Вопросы для поиска:** «не создан config», «config.json отсутствует», «конфиг», «рабочая папка», «working directory», «первое перемещение», «перетаскивание».

Согласно README, `config.json` сохраняется в **рабочей папке** приложения; эта папка не должна быть защищена от записи. Важная оговорка: файл создаётся только после того, как overlays впервые «затронуты», обычно после их перемещения или изменения размера. Если файла пока нет, сначала войдите в режим Alt+J и переместите или измените размер overlay; проверьте рабочую папку, из которой запущено приложение, и возможность записи в неё. README не утверждает, что одного перезапуска достаточно для создания файла. Источник: upstream `README.md`, строки 114–116 и 126–130.

## Delta ghost выключен или не отображается

**Вопросы для поиска:** «Delta ghost», «призрак», «ghost off», «не показывается ghost», «ghost last best session_best», «target».

Параметр Delta **`ghost`** управляет пунктирной ghost-трассой и в таблице README имеет варианты `off` (значение по умолчанию), `last`, `best`, `session_best`. `off` отключает ghost; `last` выбирает последний завершённый круг; `best` и `session_best` обозначены как лучший круг и в README указаны как в данный момент одинаковые. Если в `config.json` явно стоит `ghost: off`, README подтверждает, что ghost отключён; можно выбрать один из документированных вариантов, чтобы запросить трассу.

Не путайте `ghost` с отдельным параметром **`target`**: README перечисляет для него `session_best` (по умолчанию) и `best`; он задаёт круг-ориентир для live delta. Если пользователь не сообщил текущее значение `ghost`, не угадывайте: попросите проверить раздел Delta в `config.json`. Источник: upstream `README.md`, строки 83–90 (описание Delta и таблица `target`/`ghost`).

## Уровни доказательности

- Это ответы по документации iRon, а не подтверждение того, что конкретный профиль, Windows-компьютер или игра были проверены.
- Рекомендация использовать borderless документирована; работоспособность иных режимов в README отмечена автором как непроверенная.
- Используйте только перечисленные в исходном README значения `ghost` и `target`; документация не подтверждает дополнительные значения или обходные решения.
